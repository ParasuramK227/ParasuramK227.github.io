## What this is

A single-page portfolio with a WebGL hero ("Signal Core"), a light/dark theme
pair, and seven content sections. Everything is static: no backend, no
analytics, no tracking, no third-party requests at runtime.

Sections: hero · about · skills · projects · timeline · activity · transmissions
· contact.

### Two things worth knowing

**The hero is a deliberate dark console in both themes.** It is a terminal
viewport framed as such, so the theme toggle changes the page around it rather
than washing it out. The hero exposes its own colour scale
(`--c-hero-*`) and the header borrows it while floating on top.

**Project status is honest.** Anything in progress is labelled `IN PROGRESS`
and anything without a public repository says so. The Go/TUI entry is
explicitly a work in progress, not a shipped product.

## Running it

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

```bash
npm run typecheck  # tsc --noEmit
npm run lint       # eslint
npm run build      # typecheck + production build into dist/
npm run preview    # serve dist/
npm run stats      # regenerate src/data/github-stats.json from the GitHub API
```

### Deploying

`.github/workflows/deploy.yml` builds on every push to `main` and publishes
`dist/` to GitHub Pages. The site is served from the repository root, so
`base` is `/`; set `VITE_BASE_PATH` to override that for a sub-path deploy.

## Architecture

```
src/
  App.tsx                 section order + providers
  components/
    three/                the hero scene, shaders and its performance guard
    hero/                 hero layout and copy
    layout/               header, footer, theme toggle
    ui/                   Button, Chip, Panel, Reveal, Section …
    about/ skills/ projects/ timeline/ stats/ blog/ contact/ terminal/
  data/                   site, projects, skills, timeline, posts, GitHub snapshot
  content/posts/          markdown source for the transmissions section
  lib/                    theme, palette, hooks, accent maps
  styles/                 tokens.css (design tokens) + global.css
```

### Design tokens

`src/styles/tokens.css` defines a semantic OKLCH palette — `canvas`, `surface`,
`elevated`, `line`, `line-strong`, `ink`, `muted`, `faint`, `accent`, `signal`,
`info`, `ok`, `danger` — and maps it into Tailwind through `@theme inline`.
Both themes are checked so that body text clears 4.5:1 on canvas, surface and
elevated, and `line-strong` clears 3:1 for input borders.

Base element styles live in `@layer base`. That matters: an unlayered
`a { color: inherit }` outranks Tailwind's utilities and silently strips the
colour from every link.

### The 3D scene

`SignalCore` is a noise-displaced wireframe icosahedron with three
counter-rotating orbit rings, a satellite, an infinite shader grid floor with a
scan ring, and a drifting glyph particle field. Bloom, chromatic aberration and
a vignette finish it.

Performance is a hard constraint, not an afterthought:

- The whole scene is `React.lazy`-loaded behind `Suspense`, so first paint never
  waits on Three.js.
- DPR is capped at 1.75 (1.5 on small screens).
- `frameloop` pauses whenever the hero leaves the viewport.
- `PerformanceGuard` samples frame time and degrades — dropping post-processing
  and particle count, then lower DPR — if the average frame exceeds 30 ms.
- `prefers-reduced-motion` renders one static frame and stops.

### Accessibility

- Keyboard reachable throughout; `⌘K` / `Ctrl+K` opens the terminal palette and
  `Escape` closes it from anywhere.
- The palette traps focus and is announced as a modal dialog.
- Every interactive element meets the 24 × 24 CSS px target minimum.
- Live regions announce theme changes, clipboard copies and the palette state.
- The page is verified at 320, 390, 768, 1024 and 1440 px in both themes.

## Preserved pages

`public/FlowBoard/index.html` is an earlier Framer export that was already
published at `/FlowBoard/`. It ships byte-for-byte with the build so publishing
this site does not break that URL. It is not part of the portfolio and is not
linked from it.

## Content sources

`src/data/github-stats.json` is a snapshot generated by
`scripts/fetch-github-stats.mjs`. It is committed on purpose so the page never
depends on a live API call; re-run `npm run stats` to refresh it.

The transmissions section ships two drafts. They are marked `draft` in the data
layer and rendered with a visible `DRAFT` chip rather than being presented as
published writing.
